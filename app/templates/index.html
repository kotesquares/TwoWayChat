⚙️ AI 英会話チューター & VOICEVOX 設定

RunPodに接続する場合は「RunPod Serverless」を選択してください。
RunPod User Settings > API Keys から取得したAPIキー。
Serverless Endpoints 一覧に表示されているエンドポイントID。
自前のPCで動いている VOICEVOX アプリのURL。日本語会話のアドバイスを高音質で読み上げます！

🎓 チューター別 学習カスタマイズ指示（日本語訳の有無・指導方針など）

カンマやスペースで区切って自由に追加指示を入力できます。
例: 返答の末尾に日本語訳をつける, 文法修正を積極的に行う, TOIEC表現を多めにする

RunPod側で読み込んでいるモデル名 (推奨: gemma2:9b または llama3.1:8b)。
言葉に詰まった際、AIチューターが自発的に次の質問や助き船を出してくれるまでの待ち秒数。

📖 AI 英会話チューターの使い方 & RunPod 設定

AIチューターがあなたの英語力を分析し、日本語で丁寧にアドバイスしながら自発的に楽しくレッスンを引っ張ってくれます！

💡 効果的な学習のコツ

・日本語で「これ英語でなんて言うの？」「日常会話を練習したい！」と話しかけてOKです！
・間違った英語を気にせずどんどん送信してください！AIが日本語で優しく解説・訂正してくれます。
・返答に困ったら少し待ってみてください。AIチューターが自発的にヒントや次の質問を投げかけてくれます！

ステップ: RunPod キーの入力

RunPod Settings から API Key と Endpoint ID を取得し、設定画面に入力するだけでレッスンを開始できます！
