📖 あなたがRunPod側で行う作業まとめ

RunPod上で作業が必要な手順は以下の 2つのID/キーの取得・コピーのみ です。

ステップ 1: RunPod API Key の取得

1. RunPod Settings (API Keys) を開きます。
2. 「+ API Key」 ボタンを押し、作成されたキー（例: rpa_...）をコピーします。

ステップ 2: Endpoint ID の取得

1. RunPod Serverless Console を開きます。
2. 作成済みの Runpod Worker Ollama エンドポイントのID（例: vllm-xxxxx や abc123xyz）をコピーします。

ステップ 3: モデル確認

RunPodの Edit Endpoint の環境変数にて、OLLAMA_MODEL_NAME が gemma2:9b になっていることを確認してください。
※Secrets設定（暗号化）は一切不要です！無視して進めて問題ありません。

⚙️ RunPod Serverless 接続設定

RunPodに接続する場合は「RunPod Serverless」を選択してください。
RunPod User Settings > API Keys から取得したAPIキー。
Serverless Endpoints 一覧に表示されているエンドポイントID。
RunPod側で読み込んでいるOllamaモデル名。
AIの返答が画面に届いてから、自発的に会話をリードし始めるまでの秒数。
